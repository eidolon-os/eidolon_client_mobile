# Companion 预设：Mobile 状态（2026-09-17）

## 结论

“选模板直接创建”的新流程已在 Mobile 实现，本地 1033 项测试全绿。音色选择这条轴
按产品决定整条移除，不在本阶段。**端到端尚未验收**：Host 上跑的仍是旧 Data，真机
上还没有见过第四份模板，也没有创建过测试伙伴。

## 范围决定：音色不做

创建和编辑流程里都没有音色选择、试听或可用性提示。伙伴不携带自己的声音，说话的
声音由这台主机的 Channel 配置决定。曾经实现过的那一版（Data 声音档案、Admin 试听
桥、Channel 会话内换 TTS、Android 播放器、下拉选择）已全部撤回，原因是它把“选一个
模板就能开始”重新变复杂了，而且带来两个实打实的缺陷：会话内绑定失败会让任务在
`session_end` 之前就死掉（设备拿着开着的麦对着空房间），以及 Channel 不可达时创建
按钮会整个灰掉。将来若要重做，这两处必须先有答案，不要从现在的任何字段去推断。

## 已实现（本地测试覆盖）

- 首屏直接列出模板，点一下选中即可创建；名字和详细设定都是可选调整。
- 自定义入口保留，自定义走“继续 → 确认”两步；选模板则一步创建。
- 每个模板和自定义各自保留草稿，来回切换、退出再进都不丢。
- 创建期间禁止重复提交；结果不确定时锁住草稿，重试复用同一个 operation ID 和同一份
  请求体；4xx 是主机的决定，解锁草稿允许改了再试，并显示主机给出的原因。
- 创建成功后可直接进入这个伙伴的对话，也可稍后再聊。
