# 保存团队与运行边界

本文为早期概要。完整评审以 [角色团队独立管理产品与技术设计](../../docs/IP团队/角色团队独立管理产品与技术设计-20261029.md) 为准（跨仓文档路径见工作区 docs/IP团队）。

## 产品流程

伙伴管理是独立入口，管理已有伙伴及角色资料。团队管理是另一个独立入口，创建、编辑、删除多个团队。开始对话只选择已保存团队并启动；连续回复上限放入默认折叠的高级设置。沿用现有 Host 选择、设备添加、配网和连接流程。

## 数据归属

团队归属于现有 Owner、Host 权限范围，不能仅用显示名称隔离。团队配置包含稳定 ID、名称、版本、输入设备、成员伙伴 ID、对应输出设备、角色说明、交流目标与回复上限。伙伴是引用资产，删除团队不删除伙伴，不改变设备绑定。

团队配置与运行会话分离。每次启动生成会话 ID，使用一个固定配置版本。保存修改只影响下次启动。配置版本必须保存预期伙伴绑定，不能在设备换绑后悄悄替换团队成员。配置同步位置需要结合现有 Data 资产接口实现，手机偏好不能充当 Host 运行状态权威。

## 启动与占用

沿用 Hub 的 Owner 鉴权与设备预检，Channel 是其现有 Provider 范围内运行占用的权威。启动应在同一临界区验证所有设备、伙伴与占用，再一次性登记。伙伴允许被多个已保存团队引用，但不能在两个运行团队同时使用；设备亦不能重复占用。单聊必须参与同一冲突检查。冲突返回占用会话及可展示的团队名称，不自动结束、抢占或解绑。

离线、权限撤销、绑定改变或成员缺失必须拒绝启动并指明需要修复的配置。不能只在手机禁用按钮，也不能先发出设备加入命令再检查冲突。不引入跨 Host 全局锁服务。

## 生命周期

等待用户、静默和返回页面不释放占用。结束须等待 Host 确认清理完成，清理失败保留占用并允许重试。启动响应丢失时使用原会话 ID 查询，不能生成新 ID 重开。App 重启读取持久化的 Host、Owner、会话 ID，再查询状态；不可达不能视为已结束。

Channel 已保存 prepared scene 检查点，重启时安装设备占用并完成关闭，不自动恢复生成。伙伴占用也应从同一检查点恢复；恢复清理完成后再释放。设备断线沿用现有 reachability 检查与结束流程。不得把生成完成当作实际播放完成，保留现有 decision_id 与播放审计。

## 当前实现进度

Team 资产、固定版本启动、伙伴和设备统一准入、独立管理页与按团队恢复已接入。手机通过 Host 查询未终结运行，App 重开不重发启动；正式页面保存、启动至真实设备就绪、App 重开恢复、结束、再次启动及 Host 重启清理已实机验证。首次点击试听生成并缓存，后续播放和 Host 重启后的缓存复用已验证。

当前试听针对 Host 当前配置的声音。新版错误提示、并发拒绝后的权威对账、离页停止试听已加入测试。旧临时页面与自由配置产品入口已退出，运行核心保留。真实 PTT 发言与打断、同伙伴不同设备冲突仍按完整设计的门禁验收，不将开发态回归替代这些证据。

完整进度、发布提交与验收记录统一维护在设计文档第 20 节，本概要不维护第二套任务清单。


## 2026-10-30 架构收敛

正式决策服务复用 Models participation 与 Ops 生命周期，Mobile 不配置或依赖临时网关。运行页沿既有轮询展示单轮失败并保留重试；未运行团队可查看伙伴与设备占用，并进入具体占用团队处理。占用判定仍以 Host 的运行快照和 Provider 权威为准。
